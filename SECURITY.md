# Reporting a Security Issue

Please do not publish exploitable vulnerabilities, credentials, or private user data in a public issue.

Report suspected security problems privately to the repository maintainer through a private GitHub security advisory if enabled. Include affected version/commit, impact, reproduction steps, and a suggested mitigation when possible.

Do not include live secrets or real client records in a report. Rotate any credential that may have been exposed.

FormaCMS is an evolving starter project; do not assume it has undergone an independent security audit.
